# 🎓 Study Tutor AI

A simple AI Study Tutor built with:

- Streamlit
- CrewAI
- Groq
- GPT-OSS 120B

## Features

- AI tutoring
- Difficulty adaptation
- Conversation memory
- Calculator tool
- Study plan tool
- Modern responsive UI

## Deployment

The application is designed to be deployed on Render using GitHub.
